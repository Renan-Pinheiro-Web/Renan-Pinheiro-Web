## 📂 Projetos de destaque

Os repositórios públicos aqui são projetos pessoais e de estudo. Os projetos desenvolvidos para clientes reais estão em repositórios privados — abaixo um resumo de cada:

### 🍔 ComandAI — Plataforma SaaS para Restaurantes
Plataforma web multi-tenant para hamburguerias, pizzarias e açaiterias, com fluxo completo de PDV: mesas, comanda, cardápio e caixa. Sistema funcional com cliente ativo.

`Next.js` · `TypeScript` · `Tailwind CSS` · `Supabase` · `Vitest` · `Playwright` · `GitHub Actions`

### ⚙️ Sistema de Gestão Empresarial (ERP)
Sistema ERP completo com gestão de produtos, estoque, vendas, clientes e painel administrativo. Segundo relato do cliente, o sistema ajudou a eliminar uma perda de 30% do lucro, multiplicar as vendas por 8x e reduzir em 45% a perda de estoque.

`React` · `JavaScript` · `Tailwind CSS` · `Supabase`

### 🛒 Site de Marca com E-commerce
Loja virtual com carrinho de compras, integração com WhatsApp e painel administrativo completo. A digitalização da loja resultou em aumento de 40% nas vendas do cliente.

`Vue.js 3` · `Next.js` · `JavaScript` · `Tailwind CSS` · `Supabase`

### 🚀 Landing Page com Painel de Leads
Landing page para captação de leads integrada a painel administrativo com CRUD e integração com sistema de gestão externo.

`HTML` · `CSS` · `JavaScript` · `MySQL`
